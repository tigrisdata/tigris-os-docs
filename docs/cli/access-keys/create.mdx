# tigris access-keys create

Create a new access key with the given name. Returns the key ID and secret
(shown only once). Created keys use the `standard` scope. They receive
[default allowed operations](/docs/iam/manage-access-key/#default-allowed-operations)
even if you assign no bucket role.

**Alias:** `c`

## Usage

```bash
tigris access-keys create <name>
t3 keys c <name>
```

## Examples

```bash
tigris access-keys create my-ci-key
```
