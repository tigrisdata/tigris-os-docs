# tigris buckets

Create, inspect, update, and delete buckets. Buckets are top-level containers
that hold objects.

**Alias:** `b`

## Usage

```bash
tigris buckets <operation> [flags]
t3 b <operation> [flags]
```

## Commands

| Command                                  | Description                                                       |
| ---------------------------------------- | ----------------------------------------------------------------- |
| [`list`](list)                           | List all buckets                                                  |
| [`create`](create)                       | Create a new bucket                                               |
| [`rebase`](rebase)                       | Update a fork with the latest changes from its source             |
| [`merge`](merge)                         | Merge a fork's changes back into its source                       |
| [`get`](get)                             | Show details for a bucket                                         |
| [`delete`](delete)                       | Delete a bucket                                                   |
| [`restore`](restore)                     | Restore a soft-deleted bucket                                     |
| [`purge`](purge)                         | Permanently destroy soft-deleted buckets                          |
| [`set`](set)                             | Update bucket settings                                            |
| [`enable-snapshots`](enable-snapshots)   | Enable snapshots on an existing bucket                            |
| [`disable-snapshots`](disable-snapshots) | Disable snapshots on an existing bucket                           |
| [`lifecycle`](lifecycle)                 | Manage lifecycle rules (storage-class transitions and expiration) |
| [`set-migration`](set-migration)         | Configure data migration from an external source                  |
| [`migrate`](migrate)                     | Actively migrate objects from a shadow bucket                     |
| [`set-notifications`](set-notifications) | Configure object event notifications                              |
| [`set-locations`](set-locations)         | Set the data locations for a bucket                               |
| [`set-cors`](set-cors)                   | Configure CORS rules                                              |
| [`share`](share)                         | Share a bucket with your organization, teams, or users            |

`set-ttl` and `set-transition` have been replaced by
[`buckets lifecycle`](lifecycle).

## Examples

```bash
tigris buckets list
tigris buckets create my-bucket
tigris buckets get my-bucket
tigris buckets set my-bucket --access public
tigris buckets delete my-bucket
```
