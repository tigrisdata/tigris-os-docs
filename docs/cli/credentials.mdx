# tigris credentials

Test whether your current credentials can reach Tigris, and issue
[temporary credentials](/docs/iam/temporary-credentials/) limited to one bucket.

**Alias:** `creds`

## Usage

```bash
tigris credentials <operation> [flags]
t3 creds <operation> [flags]
```

## Examples

```bash
tigris credentials test
tigris credentials test --bucket my-bucket
tigris credentials temporary my-bucket --name ci-upload --access write
```
