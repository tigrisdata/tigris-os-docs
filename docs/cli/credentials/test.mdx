# tigris credentials test

Verify that current credentials are valid. Optionally checks access to a
specific bucket.

**Alias:** `t`

## Usage

```bash
tigris credentials test [flags]
t3 creds t [flags]
```

## Flags

| Name             | Required | Default | Description                                   |
| ---------------- | -------- | ------- | --------------------------------------------- |
| `--bucket`, `-b` | No       | —       | Bucket name to test access against (optional) |

## Examples

```bash
# Test general access
tigris credentials test

# Test access to a specific bucket
tigris credentials test --bucket my-bucket
```

## Temporary credentials

[Temporary credentials](/docs/iam/temporary-credentials/) cannot list buckets,
so pass `--bucket` with the bucket they were issued for.

If their policy does not allow `s3:ListBucket`, for example write-only
credentials, the test still passes. It shows that the credentials are valid but
cannot list the bucket, and that object access was not checked. With
`--format json`, the output has `"canList": false`.
