# tigris objects delete

Delete one or more objects by key from the given bucket. On a versioned bucket,
the default creates a delete marker; use `--version-id` or `--all-versions` to
hard-delete versions.

**Alias:** `d`

## Usage

```bash
tigris objects delete <bucket> <key> [flags]
t3 o d <bucket> <key> [flags]
```

## Flags

| Name             | Required | Default | Description                                                                                              |
| ---------------- | -------- | ------- | -------------------------------------------------------------------------------------------------------- |
| `--version-id`   | No       | —       | Hard-delete a specific object version (requires bucket versioning). Targets a single key                 |
| `--all-versions` | No       | —       | Hard-delete every version and delete marker for the given key(s). Mutually exclusive with `--version-id` |
| `--yes`, `-y`    | No       | —       | Skip confirmation prompts                                                                                |

## Examples

```bash
# Delete a single object
tigris objects delete my-bucket old-file.txt

# Delete multiple objects
tigris objects delete my-bucket file-a.txt,file-b.txt

# On a versioned bucket: delete a specific version (hard delete)
tigris objects delete my-bucket old-file.txt --version-id abc123 --yes

# On a versioned bucket: nuke every version and delete marker for a key
tigris objects delete my-bucket old-file.txt --all-versions --yes
```

## Buckets with soft delete enabled

On a bucket with [soft delete](/docs/buckets/soft-delete) enabled, a plain
`objects delete` does not destroy the object — it keeps a recoverable copy for
the bucket's retention window. List those with
[`objects list --deleted`](/docs/cli/objects/list) and bring one back with
[`objects restore-deleted`](/docs/cli/objects/restore-deleted).

To destroy a soft-deleted version ahead of its retention window, use
[`objects purge`](/docs/cli/objects/purge) rather than `--version-id`. A
versioned delete aimed at a soft-deleted version is rejected; `--version-id`
here is for hard-deleting a version of a _live_ object on a versioned bucket.
