# tigris objects list

List objects in a bucket, optionally filtered by a key prefix.

**Alias:** `l`

## Usage

```bash
tigris objects list <bucket> [flags]
t3 o l <bucket> [flags]
```

## Flags

| Name                  | Required | Default | Description                                                                 |
| --------------------- | -------- | ------- | --------------------------------------------------------------------------- |
| `--prefix`, `-p`      | No       | —       | Filter objects by key prefix (e.g. "images/" to list only images)           |
| `--format`, `-f`      | No       | `table` | Output format. Options: `json`, `table`, `xml`                              |
| `--limit`             | No       | —       | Maximum number of items to return per page                                  |
| `--page-token`, `-pt` | No       | —       | Pagination token from a previous request to fetch the next page             |
| `--deleted`           | No       | —       | List [soft-deleted](/docs/buckets/soft-delete) objects instead of live ones |

## Examples

```bash
tigris objects list my-bucket
tigris objects list my-bucket --prefix images/
tigris objects list my-bucket --format json
```

## Listing soft-deleted objects

On a bucket with [soft delete](/docs/buckets/soft-delete) enabled, `--deleted`
switches the listing over to the objects that have been deleted but are still
inside their retention window:

```bash
tigris objects list my-bucket --deleted
tigris objects list my-bucket --prefix contracts/ --deleted
```

This is a separate view rather than an addition — the output contains only
deleted objects, and live ones are left out. `--prefix`, `--limit`, and
`--page-token` work the same way here.

To act on one of these entries you need a version ID, which
[`objects list-versions --deleted`](/docs/cli/objects/list-versions) provides.
From there, [`objects restore-deleted`](/docs/cli/objects/restore-deleted)
brings a version back and [`objects purge`](/docs/cli/objects/purge) destroys
one permanently.
