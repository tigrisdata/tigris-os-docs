# tigris organizations

List, create, and switch between organizations. An organization is a workspace
that contains your resources like buckets and access keys.

**Alias:** `orgs`

## Usage

```bash
tigris organizations <operation> [flags]
t3 orgs <operation> [flags]
```

## Commands

| Command            | Description                                             |
| ------------------ | ------------------------------------------------------- |
| [`list`](list)     | List your organizations and select the active one       |
| [`create`](create) | Create a new organization                               |
| [`select`](select) | Set the active organization for all subsequent commands |
| [`delete`](delete) | Delete an organization you own                          |

## Examples

```bash
tigris orgs list
tigris orgs create my-org
tigris orgs select my-org
tigris orgs delete
```
