# tigris usage

Show the active organization's usage and charges for a billing month — the same
breakdown as the Usage page in the console. Requires OAuth login.

## Usage

```bash
tigris usage [flags]
t3 usage [flags]
```

The table lists every line item that has usage this month, with the quantity you
used, the quantity billed (they differ only when a plan minimum applies), and
the amount, followed by the subtotal, any credits, and the total. Line items
with zero usage are hidden unless you pass `--all`.

## Flags

| Name       | Required | Default       | Description                                                                                                                     |
| ---------- | -------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `--month`  | No       | current month | Billing month as `YYYY-MM`                                                                                                      |
| `--all`    | No       | —             | Show every line item, even those with zero usage                                                                                |
| `--format` | No       | `table`       | Output format. Options: `json`, `table`, `xml`. `json` returns the full invoice, including per-item tiers and the invoice state |

## Examples

```bash
# This month's usage and charges
tigris usage

# A previous month
tigris usage --month 2026-09

# Include the line items you have not used
tigris usage --all

# The full invoice as JSON
tigris usage --format json
```

When your plan has a minimum commitment it is listed above the subtotal, and a
note under the table explains that the total is the greater of the two, less
credits. When the invoice can be paid or has a receipt, the link is printed
after the table.
